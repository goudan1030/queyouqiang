雀有腔是一个以四川麻将牌桌文化为主题的音效浏览与播放项目，提供原生微信小程序和浏览器预览。朱砂红、米白底色与麻将牌元素组成界面，按人声台词、牌型报牌、音效音乐三个入口组织内容。

> **本仓库不包含任何音频文件，也不提供音频下载地址。** 开源内容包括程序代码、界面与目录元数据。第三方录音、配音、音乐及相关素材的权利属于各自权利人，不适用本仓库的 MIT 代码许可。克隆后可以浏览界面、搜索和筛选；实际播放需自行配置合法授权的本地音频。

## 功能

- **三类内容入口**：人声台词、牌型报牌、音效音乐分别浏览，支持内容、角色、性别和关键词组合筛选。
- **完整播放器**：播放 / 暂停、进度、上一条 / 下一条、随机播放、循环与版本切换。
- **本机收藏与记录**：收藏和最近播放保存在当前设备，无需登录。
- **微信分包加载**：按需异步加载音效包，预热可见内容，复用加载请求与缓存，失败后支持重试。
- **适配移动端**：双列卡片、长句换行、分页加载、底部播放器与分享封面。
- **双端共用目录**：微信小程序与 Web 使用同一份目录和筛选逻辑，无需业务后端。

当前目录元数据索引了 603 个内容条目、883 个来源记录，对应 858 份去重录音、15 个音频分包。**这些数字表示目录规模，不表示仓库附带相应音频。** 元数据中的台词由本地识别辅助整理，可能存在方言识别偏差。

## 快速开始

需要 Node.js 18 或更新版本。项目没有 npm 运行时依赖，无需执行 `npm install`。

```sh
git clone https://github.com/goudan1030/queyouqiang.git
cd queyouqiang
npm run dev
```

浏览器打开 <http://localhost:4173>。按 `/` 聚焦搜索框，空格控制播放 / 暂停。未配置音频时，目录与界面可浏览，点击播放会提示加载失败；这是不附带第三方素材的预期状态。

### 微信小程序

1. 将 `miniprogram/project.config.example.json` 复制为同目录的 `project.config.json`。
2. 用微信开发者工具导入 `miniprogram/`。
3. 将示例的 `touristappid` 替换为自己的小程序 AppID；测试号能力以开发者工具实际支持为准。
4. 按[音频配置说明](docs/AUDIO.md)准备已获授权的资源，再测试真实播放与分包加载。

本人的 AppID 和私有开发配置未提交。仓库保留分包入口代码，分包下的 `audio/` 目录由 Git 忽略。

```text
├── index.html / app.js / styles.css   Web 界面与播放逻辑
├── assets/                           品牌图形与封面源文件
├── miniprogram/
│   ├── pages/index/                  小程序页面
│   ├── utils/catalog.js              共用筛选逻辑
│   ├── utils/shushan.js              目录元数据，不包含音频内容
│   ├── utils/load-pack.js            分包加载入口
│   ├── packs/                        分包页面与入口，不含音频
│   └── project.config.example.json   无个人 AppID 的配置示例
├── scripts/                          本地服务器、素材导入与发布检查
├── tests/                            目录、筛选与播放器行为测试
└── docs/                             音频说明与展示图片
```

## 验证

```sh
npm test                 # 无音频也可运行；跳过录音文件完整性检查
npm run check:public     # 检查 Git 暂存区：音频、容器、归档与私人配置
npm run test:audio       # 仅在本地已配置完整音频时运行
```

测试覆盖目录一致性、组合筛选、收藏、最近播放、分包重试、并发切换、后台暂停和分享封面。GitHub Actions 会在推送和拉取请求时运行无音频测试及发布检查。音频测试额外检查文件摘要、时长元数据、分包与总体大小。
